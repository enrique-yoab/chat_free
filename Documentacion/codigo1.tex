\subsection{\large Archivo de Cabecera \texttt{(header.h)}}
Este archivo contiene las declaraciones de las estructuras de datos y la definción de las funciones utilizadas para la implementación del proyecto. 
\begin{itemize}
    \item \textbf{Estructura de Datos:} Se definen 2 estructuras principales; \texttt{Mensaje} y \texttt{TipoMensaje}. La primera encapsula la información relevante de cada mensaje, el id del proceso que lo envía, el contenido del mensaje, la IP y el puerto del nodo remoto, así como el tipo de mensaje que se está transmitiendo. La segunda estructura, es un enumerado que categoriza los mensajes en tres tipos; \texttt{ENVIO}, \texttt{RECIBIDO} y \texttt{SALIDA}, lo que permite una gestión eficiente de los flujos de datos y la lógica de control entre ambos procesos.
    \item \textbf{Funciones del Back-End:} se usan 8 funciones para el proceso de red, cada una con un rol especifico en la gestión de la comunicación y la concurrencia. Estas funciones incluyen los hilos lectores y escritores tanto para la comunicación P2P como para las tuberías. Y dos funciones auxiliares para capturar el tiempo en milisegundos y otro para convertirlo a formato de texto.
    \item \textbf{Funciones del Front-End / Interfaz:} Se definen 3 funciones destinadas a la gestión de la interfaz gráfica de usuario y su interacción asíncrona con las tuberías de comunicación interprocesos. Estas comprenden un hilo lector especializado en recuperar los datos entrantes del \textit{backend} para delegar su renderizado en burbujas sin bloquear la fluidez de la ventana visual, un hilo escritor responsable de monitorizar y canalizar los mensajes de salida capturados desde la entrada de texto, y la rutina maestra de inicialización encargada de estructurar el entorno gráfico con GTK, instanciar la concurrencia del \textit{frontend} y desplegar los componentes en pantalla.
\end{itemize}

\subsubsection{\large Codigo}
\begin{lstlisting}[style=estiloC, caption={Archivo de declaraciones compartidas entre el Backend y el Frontend}]
#ifndef HEADER_H
#define HEADER_H
#include <gtk/gtk.h>

#define TAM_MAX 1024

typedef enum {
    ENVIO,
    RECEPCION,
    SALIDA
} TipoMensaje;

typedef struct {
    int id_emisor;          
    char texto[TAM_MAX];        
    char ip_destino[16];     
    int puerto_destino;      
    TipoMensaje tipo;
    long long tiempo;         
} Mensaje;

typedef struct {
    int A[2]; // Interfaz <-- Backend (Backend escribe en A[1], Interfaz lee en A[0])
    int B[2]; // Interfaz --> Backend (Interfaz escribe en B[1], Backend lee en B[0])
} Tuberia;

// Prototipos del Backend (conexion.c)
void *hilo_lector_p2p(void *arg);
void *hilo_escritor_p2p(void *arg);
void *hilo_lector_pipe(void *arg);
void *hilo_escritor_pipe(void *arg);
void conexion(Tuberia *local);
void enviar_msj(char *ip_destino, int puerto_destino, Mensaje msg);
long long get_time_ms();
void formatear_tiempo_str(long long tiempo_ms, char *buffer_salida);

// Prototipos del Frontend / Interfaz (interfaz.c)
void *hilo_lector_gui(void *arg);
void *hilo_escritor_gui(void *arg);
void interfaz_grafica(int argc, char *argv[], Tuberia *padre);

#endif
\end{lstlisting}
